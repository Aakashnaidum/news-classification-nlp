# Provenance and Attribution

This file records what is known about the origin of this repository and what should not be inferred from it.

## Source status

The project began from a third-party academic project package that was shared by a classmate. The exact upstream repository, download page, vendor, dataset source, and license terms are not currently known.

Because the original redistribution rights are unresolved, this repository should be treated as a portfolio and review artifact, not as an open-source project that grants reuse rights.

## What came from the base project

The base package provided the broad project idea: news classification with NLP, neural network models, datasets for fake-vs-real and category classification, and a Django-style demonstration app.

The original package is not represented here as wholly original work by Aakash Naidu.

## What this repository contributes

This repository presents a revised and documented version focused on reproducible NLP evaluation:

- duplicate and leakage checks across splits
- de-duplicated evaluation protocol
- macro F1 and per-class reporting
- TF-IDF logistic regression baseline
- saved preprocessing artifacts for inference
- tests and CI checks
- cleaned documentation and setup instructions

## Publication limits

No open-source license is granted at this time. Do not assume that the original project package, bundled datasets, model files, or derived artifacts may be reused outside review of this portfolio repository.

If the upstream source and license are later identified, this file should be updated with exact links, license text, and any required attribution.
